# 20260322-langgraph-tasklist-manager

## Development

This project uses `uv` for dependency management. To start LangGraph Studio locally:

```bash
# uv will automatically install the correct Python version and dependencies
uv run langgraph dev
```

This will spin up a local server and provide a URL to open in your browser (typically `https://smith.langchain.com/studio/...`).
